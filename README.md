# Public Space Failure

**Preserve the place. Transform the space.**

Public Space Failure is a Codex skill and creative method for reinterpreting real public, transit, architectural, and semi-public spaces through one clearly visible spatial failure.

It does not simply apply a visual style.

It asks:

**What is this space supposed to do — and what happens if one of those rules quietly stops working?**

A corridor may continue without arrival.

A staircase may descend into a lower level that cannot physically exist.

A platform may contain another platform beneath itself.

A normal service door may reveal a full-scale public corridor too large to fit behind it.

An exit may never truly become outside.

The source place remains recognizable.

The spatial logic does not.

---

## Core Idea

Public spaces make promises.

A door promises another place.

A corridor promises passage.

A staircase promises another level.

An escalator promises arrival.

A platform promises departure.

A waiting area promises an event.

An exit promises outside.

A route promises progress.

Public Space Failure preserves the identity of the real place while allowing one of those promises to fail.

The goal is not fantasy worldbuilding.

The goal is to let a real public space quietly fail from within.

---

## The Method

The method follows a simple sequence:

1. Read the real space.
2. Identify what it normally promises.
3. Preserve only the strongest identity anchors.
4. Change the spatial geometry clearly.
5. Break one spatial rule.
6. Simplify unnecessary visual noise.
7. Keep the result photographically believable.
8. Apply the final documentary image treatment last.

The final image should feel:

- quieter than the source
- emptier than the source
- more spatially exposed
- more architecturally impossible
- but still like a real photograph

---

## Preserve the Place, Not the Geometry

One of the most important principles of the method is:

**Preserve the camera and the identity of the place.**

**Do not preserve spatial geometry.**

Spatial geometry is the main editable material.

The source image should retain:

- camera position
- camera height
- framing
- perspective logic
- local architectural materials
- important signage
- transit identity
- real wear and texture
- documentary realism

But the architecture is allowed to:

- extend
- repeat
- loop
- sink
- enlarge
- layer
- overlap
- misalign
- fold
- redirect
- become spatially incompatible with itself

The place should remain recognizable.

The geometry is allowed to fail.

---

## One Failure Only

Every result should contain one dominant spatial failure.

Not many unrelated surreal ideas.

Not decorative weirdness.

Not random objects.

The failure should be easy to describe in one sentence.

Examples:

- a narrow door contains a full-scale corridor
- an escalator continues beyond its arrival floor
- a track bed contains another unreachable platform
- a corridor continues beyond plausible building depth
- an exit leads into another interior
- a station contains another version of itself

The strongest results are usually built from one simple contradiction.

---

## Core Spatial Failure Types

### Door → Larger Space

A narrow or ordinary doorway reveals a full-scale public interior too large to physically fit behind it.

### Exit → Interior

An exit appears to lead outside, but instead leads deeper into another interior.

### Infinite Continuation

A corridor, platform, passage, tunnel, or column sequence continues beyond plausible depth.

### Route → Loop

Movement continues, but progress disappears.

The route quietly returns to itself.

### Destination Failure

Architecture still directs movement, but arrival no longer resolves.

### Descent Failure

A staircase or lower route continues into a larger, deeper, or repeated lower public level.

### Layer Failure

Another version of the same platform, floor, corridor, or public room appears above, below, behind, or inside the original.

### Interior / Exterior Failure

Outside becomes enclosed.

An exit never fully becomes outside.

A courtyard behaves like an interior.

### Recursive Public Space

A public space contains another version of itself.

Examples:

- station inside station
- platform beneath platform
- corridor behind corridor
- full-scale passage inside a narrow service door

### Compression / Collapse

A large public environment reduces into a few recognizable fragments of itself.

Possible fragments include:

- station signs
- benches
- clocks
- screens
- train parts
- tiled walls
- columns
- public furniture

---

## Few Anchors, Less Clutter

Public Space Failure is built on reduction.

The method does not preserve every real-world detail.

Instead, it keeps only the minimum spatial anchors needed to preserve identity.

Typical anchors include:

- station name
- platform edge
- tiled wall
- staircase
- escalator
- train
- bench
- door
- clock
- monitor
- column rhythm
- one person if useful for scale

Everything else may be simplified.

Reduce when unnecessary:

- extra people
- advertisements
- redundant signage
- temporary warning signs
- secondary furniture
- technical clutter
- visual noise
- interface overlays

The final image should usually feel calmer and more legible than the source.

**Empty space is part of the method.**

---

## Liminal, Not Horror

Public Space Failure is influenced by liminal space and Backrooms-like spatial logic, but it is explicitly non-horror.

The desired atmosphere is:

- quiet
- suspended
- empty
- slightly uncanny
- emotionally cool
- observational
- calm but spatially wrong

Avoid:

- monsters
- gore
- horror faces
- jump scares
- haunted-house imagery
- supernatural threats
- extreme darkness
- theatrical fear

The goal is spatial uncertainty, not terror.

---

## Backrooms Logic, Not Backrooms Style

This method does not automatically turn real places into yellow office mazes.

Instead, it searches for Backrooms-like conditions already latent inside real architecture:

- impossible extension
- failed thresholds
- looping circulation
- oversized interiors
- repeated infrastructure
- unresolved destination
- excessive emptiness
- suspended public function

**Do not make reality look like the Backrooms.**

**Discover the Backrooms already hidden inside reality.**

---

## Visual Language

The visual treatment is an essential part of the method, but it is secondary to the spatial transformation.

The spatial failure comes first.

The visual treatment comes last.

The preferred image language is:

# 2000s Documentary Fluorescent Realism

The image should feel like a quiet frame from an early-2000s European documentary, public-space travel photograph, older compact-camera image, or restrained DV-era observational footage.

Preferred qualities include:

- warm yellow to slightly yellow-green fluorescent cast
- institutional public-space lighting
- dirty off-whites
- pale beige
- muted olive undertones
- tired fluorescent yellow
- low to moderate contrast
- muted colors
- slight optical softness
- gentle soft focus
- subtle halation
- fine visible grain
- slightly faded blacks
- mild haze
- modest dynamic range
- imperfect white balance
- worn architectural texture
- unpolished documentary realism

The result should not look like clean contemporary digital photography.

The impossible space should feel accidentally documented.

---

## Fluorescent Color

The yellow-green tone should feel caused by:

- real fluorescent lighting
- imperfect white balance
- older camera response
- institutional public-space illumination

It should not look like a global yellow filter.

The goal is not “yellow image.”

The goal is a believable public-space fluorescent atmosphere.

For exterior daylight scenes, believable daylight should remain intact.

The aged documentary texture may stay, while stronger yellow-green contamination should appear mainly where fluorescent or sheltered public lighting exists.

---

## Avoid Modern Digital Polish

Avoid:

- HDR
- hyper-sharp digital detail
- glossy architectural visualization
- polished CGI
- luxury editorial grading
- oversaturated color
- teal-and-orange grading
- blockbuster lighting
- strong cinematic rim light
- pristine blacks
- excessive clarity
- obvious AI sharpness
- commercial photography finish

The final image should feel slightly imperfect, observational, and physically believable.

---

## Preserve Local Identity

Public Space Failure is not tied to Berlin.

It can be used with real public spaces in:

- Berlin
- Paris
- Tokyo
- London
- Milan
- Seoul
- Athens
- Mexico City
- or any other city

Local identity should remain visible through:

- signage
- tiles
- public furniture
- train colors
- lighting character
- materials
- architecture
- transit typology
- wear and texture

Berlin should remain Berlin.

Paris should remain Paris.

Tokyo should remain Tokyo.

The spatial language may remain consistent.

The place should not disappear.

## Two Ways to Use It

Public Space Failure can be used in two different ways.

### 1. Generate Mode

Provide a real public-space photograph and call:

`Use the public-space-failure skill on this image.`

The skill should:

1. read the spatial promise
2. select a few identity anchors
3. choose one spatial failure
4. visibly change the geometry
5. simplify unnecessary clutter
6. preserve local identity
7. apply the final documentary image treatment

### 2. Spatial Critic Mode

The skill can also work as a spatial design critic or concept generator before any image is created.

Instead of generating immediately, ask it to identify:

- what the space normally promises
- which rule is most interesting to break
- which architectural geometry should change
- which elements should remain
- which clutter should disappear

This allows the user to evaluate the concept before spending time or generation budget.

The skill becomes not only an image generator, but also a creative partner for reading space.

---

## Dry Run

A dry run can be used to test a concept without generating an image.

The skill can output:

1. Source spatial promise
2. Key spatial anchors
3. The proposed spatial failure
4. Which architectural geometry changes
5. How visible the transformation would be
6. What clutter or people should be removed
7. What identity anchors remain
8. Final visual treatment
9. PASS or FAIL

A concept should only PASS if the spatial failure would remain obvious even without color grading.

## Relationship to Reality Restaged

Public Space Failure belongs to the same broader creative family as Reality Restaged.

Reality Restaged asks:

**How can documentary reality be transformed without losing its identity?**

Public Space Failure asks:

**What happens when a real public place remains recognizable, but one spatial rule quietly stops working?**

The first is broader.

The second is specifically about architecture, circulation, thresholds, public function, and spatial promises.

---

## What This Skill Is Not

Public Space Failure is not:

- a general surreal image generator
- a Backrooms preset
- a yellow-filter generator
- a horror generator
- an architecture visualization tool
- a generic cinematic style prompt
- a way to simply make images look “cool”

It is a repeatable spatial method.
