description: >
  Transform real public, transit, architectural, and semi-public photographs
  into restrained liminal images by preserving the camera, local identity,

  failure. Color grading, cleanup, emptiness, or film texture alone do not count.

# Public Space Failure

Preserve the camera.

Preserve the identity of the place.

Preserve the photographic world.

Do not preserve spatial geometry.

Spatial geometry is the main editable material.

Visual language: **2000s Documentary Fluorescent Realism.**

This visual language is not an optional finishing style.

It is a hard photographic constraint throughout the entire edit.

The result should never look like clean contemporary digital photography,
architectural visualization, polished CGI, or a newly photographed modern space.

Do not solve the spatial failure in a clean modern visual language
and attempt to add the documentary look afterward.

**CHANGE THE SPACE, NOT THE CAMERA.**

**THE SPACE MAY FAIL. THE CAMERA MUST NOT.**

If only the filter changes, the task has failed.

---

## 1. Lock the Source Identity

Preserve:

- original camera position
- camera height
- framing
- lens feeling
- perspective logic
- horizon / vanishing direction
- local architectural materials
- recognizable signage when important
- public-space or transit identity
- real wear and texture
- documentary realism

The final image should still feel like the same real place.

Do NOT interpret this as:

“leave the architecture unchanged.”

The camera and identity are locked.

The spatial geometry is not.

---

## 2. Lock the Photographic World

Before changing the architecture, identify the photographic behavior of the source.

Preserve or reinforce:

- source softness
- source exposure behavior
- source contrast range
- source white-balance imperfections
- source shadow density
- practical-light behavior
- modest highlight response
- optical imperfections
- believable noise / grain / compression
- ordinary documentary-camera realism

The transformation must remain inside the same photographic world.

The model must NOT reinterpret the source as a newly photographed contemporary scene.

Do NOT upgrade the image while changing the space.

Do NOT make it:

- cleaner
- sharper
- glossier
- more cinematic
- more expensive-looking
- more architectural
- more digitally perfect
- more professionally lit

than the source photograph.

If new architectural areas are generated,
they must inherit the photographic behavior of the original image.

New geometry must feel captured by the same camera.

The impossible architecture should look accidentally documented,
not digitally designed.

**Photographic continuity is a HARD CONSTRAINT.**

---

## 3. Read the Spatial Promise

Identify what the space normally promises.

Examples:

- door → another place
- corridor → passage
- staircase → another level
- escalator → arrival
- platform → departure
- exit → outside
- route → progress
- waiting area → an event

Then break ONE of those promises.

The failure should grow from the existing architecture.

Do not add random surreal objects.

---

## 4. FAILURE LOCK — CONTINUED EDITS

Before choosing a spatial failure,
determine whether the supplied image already contains
a clearly established public-space failure.

If the image is an already-transformed master image,
the existing failure becomes LOCKED.

Do NOT automatically choose a new failure.

Do NOT reinterpret an existing successful spatial failure
simply because another valid spatial idea is possible.

Preserve:

- failure category
- core impossible relationship
- route logic
- direction of spatial transformation
- spatial hierarchy
- established architectural contradiction
- intended destination logic
- existing inside / outside logic
- existing recursion / loop / layer logic

Only refine:

- clarity
- scale
- depth
- compression
- legibility
- architectural integration
- local geometry
- clutter
- photographic continuity

The user may ask:

- make it stronger
- make it subtler
- make it deeper
- make it narrower
- make it more obvious
- make it more realistic
- simplify it
- improve the perspective
- refine the geometry
- improve the photographic texture

These are refinement requests.

They are NOT permission to replace the existing spatial concept.

### Critical Rule

If the current master already contains:

**Route → Loop**

do NOT replace it with:

- Descent Failure
- Layer Failure
- Infinite Continuation
- Destination Failure

If the current master already contains:

**Interior / Exterior Failure**

do NOT replace it with:

- Door → Larger Space
- Recursive Public Space
- Layer Failure

If the current master already contains:

**Door → Larger Space**

do NOT replace it with:

- Infinite Continuation
- Route → Loop
- Descent Failure

unless the user explicitly requests a new concept.

A new failure may be valid in isolation
and still be WRONG for the current edit.

**A VALID ALTERNATIVE FAILURE IS STILL WRONG
IF IT REPLACES THE USER'S ESTABLISHED FAILURE WITHOUT PERMISSION.**

When editing an already-transformed master image:

**REFINE THE FAILURE. DO NOT RESELECT THE FAILURE.**

Only choose a new failure if:

- the user explicitly asks for another concept
- the user asks to restart
- the user rejects the existing failure and requests a different one
- the source image has no established failure yet

---

## 5. Spatial Geometry MUST Change

Every output must contain one clearly visible architectural or circulation failure.

Color grading, grain, lighting, atmosphere, emptiness,
cleanup, or removing people alone do NOT count.

Allowed changes include:

- extend
- enlarge
- repeat
- loop
- sink
- layer
- fold
- overlap
- enclose
- compress
- misalign
- redirect
- duplicate
- displace
- reclassify inside / outside

At least one of these must visibly change:

- spatial depth
- scale
- route continuity
- destination
- threshold behavior
- vertical movement
- interior / exterior boundary
- floor or platform layering
- architectural repetition
- public-space function

If the final result could be mistaken for the source image,
the transformation is too weak.

If only the image treatment changed,
the task has failed.

---

## 6. Choose ONE Failure

If NO existing failure is already locked,
use one dominant spatial failure only.

### Door → Larger Space

A narrow or ordinary doorway reveals a full-scale public space
too large to physically fit behind it.

### Exit → Interior

An exit leads into another interior instead of outside.

### Infinite Continuation

A corridor, platform, passage, tunnel, or column sequence
continues beyond plausible depth.

### Route → Loop

Movement continues but quietly returns to itself.

### Destination Failure

The architecture still directs movement,
but arrival disappears.

### Descent Failure

A staircase or lower route continues into a larger,
deeper, or repeated lower public level.

### Layer Failure

Another version of the same platform, floor, corridor, or room
appears above, below, behind, or within the original.

### Interior / Exterior Failure

Outside becomes enclosed,
or an exit never fully becomes outside.

### Recursive Public Space

A public space contains another version of itself.

Examples:

- station inside station
- platform beneath platform
- corridor behind corridor
- full-scale passage inside a narrow door

### Compression / Collapse

A large public environment reduces to a few recognizable fragments
of its own identity.

The failure must be clearly visible.

---

## 7. Match the Failure to the Image

### Door / threshold

Prefer:

- full-scale corridor behind a narrow door
- larger hidden interior
- exit becoming deeper interior

### Corridor

Prefer:

- impossible extension
- loop
- repetition
- unresolved destination

### Staircase

Prefer:

- clear descent failure
- larger lower public space
- repeated lower levels
- landing opening into an impossible volume

Do not merely hide steps.

### Escalator

Prefer:

- withheld arrival
- continued ascent beyond the destination
- escalator entering an impossible upper volume

### Platform / waiting area

Prefer:

- hidden lower platform
- repeated platform
- route loop
- destination failure
- public function failure

### Monitor / reflection

Prefer:

- another spatial layer
- displaced architecture
- reflection behaving physically
- observed space becoming enterable space

### Indoor / outdoor transition

Prefer:

- outside absorbed into interior
- courtyard becoming enclosed
- exit failing to become outside
- exterior objects remaining normal while the indoor / outdoor boundary fails

These recommendations apply primarily when selecting a new failure.

If the master image already contains a locked failure,
preserve that failure instead of replacing it
with another recommended category.

---

## 8. Preserve Only Key Anchors

Keep only the minimum anchors needed to preserve identity.

Usually retain 2–4:

- station name
- platform edge
- tiled wall
- staircase
- escalator
- train
- bench
- door
- clock
- monitor
- column rhythm
- one person if useful for scale

Do not preserve every real-world detail.

The anchors preserve the place.

The surrounding geometry is allowed to fail.

---

## 9. Simplify

Remove or reduce when unnecessary:

- extra people
- advertisements
- redundant signage
- background clutter
- secondary furniture
- temporary signs
- technical distractions
- visual noise
- phone / interface overlays

The final image should usually feel:

- quieter
- emptier
- more distilled
- more spatially legible

Do not preserve clutter out of habit.

Empty space is part of the method.

Do not replace removed clutter with decorative surrealism.

The image should become simpler,
not merely different.

---

## 10. Strength Test

Before rendering, ask:

Would the spatial failure still be obvious in black and white?

If no:

strengthen it.

Would the result still look almost identical to the source?

If yes:

strengthen it.

Would the result become ordinary architecture
if the color treatment were removed?

If yes:

the spatial failure is too weak.

If this is a continued edit,
also ask:

Did the failure category remain the same?

Did I refine the existing impossible relationship,
or accidentally invent a new one?

If the existing failure has been replaced:

FAIL.

Return to the locked failure.

The architectural change should be readable at thumbnail size.

But spatial strength must not destroy photographic continuity.

A strong failure should still look accidentally photographed.

---

## 11. Liminal, Not Horror

Preferred mood:

- quiet
- suspended
- empty
- slightly uncanny
- emotionally cool
- calm but spatially wrong
- observational

Avoid:

- monsters
- gore
- horror faces
- haunted-house imagery
- supernatural threats
- theatrical darkness
- jump scares
- extreme horror grading

Use Backrooms as spatial logic,
not as a visual template.

Do not automatically generate yellow office mazes.

Do not turn every public space into a conventional Backrooms environment.

Discover the Backrooms already latent inside the real place.

The viewer should first recognize reality.

The spatial mistake should reveal itself afterward.

---

## 12. Photographic Continuity — HARD CONSTRAINT

**2000s Documentary Fluorescent Realism**

This is not a decorative filter applied after the spatial edit.

It defines the photographic medium in which the entire transformation exists.

The image should feel like a real early-2000s European documentary,
travel photograph, transit photograph, or public-space observational frame
captured with ordinary older digital, compact-camera, or DV-era equipment.

The image should feel captured by:

- an ordinary traveler
- a documentary observer
- a consumer compact digital camera
- modest early-digital equipment
- imperfect practical-light conditions

Not by:

- an architectural photographer
- a commercial production crew
- a contemporary full-frame camera
- a cinematic lighting team
- a 3D visualization studio

### Preferred photographic qualities

Preserve or reinforce:

- modest resolution
- slight optical softness
- gentle soft focus
- restrained micro-detail
- weak to modest dynamic range
- imperfect white balance
- ordinary exposure
- slightly dense or noisy shadows
- subtle digital noise
- subtle compression character
- fine visible grain
- slightly faded blacks
- restrained highlight bloom
- mild halation where physically plausible
- muted colors
- low to moderate contrast
- believable shadow detail
- worn architectural texture
- unpolished documentary realism

### Fluorescent interior behavior

When fluorescent public-space lighting is present, prefer:

- warm yellow to slightly yellow-green fluorescent cast
- institutional public-space lighting
- slightly sickly but controlled fluorescent tone
- dirty off-whites
- pale beige
- muted olive-green undertones
- tired fluorescent yellow
- imperfect color separation
- practical-light contamination

The yellow-green cast should feel caused by:

- real fluorescent public-space lighting
- imperfect white balance
- older digital camera response
- institutional interior illumination

It must NOT look like a simple global yellow filter.

### Important

The photographic treatment must feel **captured**, not applied.

Do not create a clean image first
and then simulate age with grain.

Do not treat softness, weak dynamic range,
imperfect white balance, or fluorescent contamination
as optional post-processing effects.

They belong to the photographic reality itself.

Generated architectural areas must inherit these properties
at the moment they are created.

**CHANGE THE SPACE, NOT THE CAMERA.**

**THE SPACE MAY FAIL. THE CAMERA MUST NOT.**

---

## 13. Exterior Daylight Rule

If the source image is outdoors,
do not force the entire image into artificial yellow-green lighting.

Preserve believable daylight.

Still retain:

- subdued documentary color
- modest contrast
- slight grain or early-digital noise
- gentle softness
- imperfect camera response
- mildly aged image texture
- restrained dynamic range
- ordinary travel-photography exposure

If sheltered fluorescent areas exist,
the yellow-green cast may appear locally.

Color should remain physically believable.

The 2000s documentary language should come from
camera behavior and photographic imperfection,
not from forcing every scene into the same color palette.

---

## 14. Avoid Modern Digital Polish

Avoid:

- HDR
- hyper-sharp digital detail
- glossy architectural visualization
- polished CGI
- luxury editorial grading
- oversaturated color
- teal-and-orange grading
- blockbuster lighting
- strong cinematic rim light
- pristine blacks
- pristine whites
- excessive clarity
- perfect microcontrast
- obvious AI sharpness
- commercial photography finish
- ultra-clean contemporary digital photography
- polished real-estate photography
- high-end architectural photography
- physically perfect 3D-render surfaces

If the final image looks clean,
neutral,
modern,
commercial,
or digitally polished:

the photographic continuity test has failed.

Restore:

- softer contrast
- modest detail
- optical softness
- faded blacks
- imperfect white balance
- restrained dynamic range
- noisy / dense shadows
- fluorescent documentary texture where appropriate
- ordinary consumer-camera realism

Do not simply add stronger grain.

The entire photographic response must feel older and less perfect.

---

## 15. Execution Order

Always work in this order:

1. Read the source spatial promise.

2. Select 2–4 key identity anchors.

3. Lock the source photographic world:
   - softness
   - exposure
   - white balance
   - dynamic range
   - noise / grain
   - practical-light behavior
   - camera imperfection

4. Determine whether a spatial failure already exists.

   If NO:
   choose ONE spatial failure.

   If YES:
   LOCK the existing failure.

5. If the failure is locked,
   identify exactly what may be refined
   WITHOUT changing the failure category.

6. Change or refine the spatial geometry clearly
   WITHOUT leaving the locked photographic world.

7. Make every newly generated architectural area inherit
   the same photographic behavior immediately.

8. Simplify clutter and unnecessary people.

9. Preserve local identity.

10. Verify the spatial failure works without relying on color grading.

11. Verify that a continued edit has preserved
    the same failure category and impossible relationship.

12. Verify the result still looks like an imperfect
    early-2000s documentary / travel photograph.

13. Apply only minor finishing adjustments if necessary.

Do NOT generate a clean modern image first
and attempt to age it afterward.

Do NOT interpret photographic continuity
as a final filter stage.

Do NOT reinterpret an already-established failure
during a refinement edit.

Spatial structure is the editable material.

The selected spatial failure is conceptually locked once established.

Photographic reality remains continuous throughout.

---

## 16. Triple Validation Test

Before accepting the result,
perform THREE separate tests.

### TEST A — Spatial Failure

Ask:

Is the architectural or circulation failure clearly visible?

Would it still be understandable without the color treatment?

If no:

FAIL.

Strengthen the spatial geometry.

### TEST B — Failure Continuity

If this is a continued edit, ask:

Is this still the SAME spatial failure as the master image?

Has the same impossible relationship been preserved?

Did the route logic remain conceptually unchanged?

Did I refine the failure
instead of replacing it?

If no:

FAIL.

Return to the established failure.

Do NOT justify a replacement
simply because the new failure also looks interesting.

### TEST C — Photographic Continuity

Ask:

Does this still look like an ordinary,
slightly imperfect early-2000s documentary or travel photograph?

Does the newly generated architecture share the same:

- softness
- dynamic range
- white balance behavior
- noise
- exposure
- practical-light character

as the rest of the image?

If no:

FAIL.

Do not change the spatial concept.

Correct only the photographic continuity.

### PASS

PASS only when all applicable tests are true:

1. the spatial rule has clearly failed;
2. an existing failure has not been replaced;
3. the photographic world has remained intact.

A successful result should feel like:

**an impossible space accidentally captured by an ordinary camera.**

Not:

**a surreal environment deliberately rendered by a computer.**

And not:

**a different spatial concept invented during revision.**

---

## 17. Dry Run Mode

If the user asks for a dry run:

Do not generate or edit an image.

Treat requests for **Spatial Critic Mode**,
concept analysis,
or failure analysis
as Dry Run Mode.

Output only:

1. Source spatial promise
2. 2–4 key spatial anchors
3. Source photographic-world lock
4. Existing failure: YES / NO
5. If YES: locked failure category
6. If NO: proposed single spatial failure
7. Which architectural geometry visibly changes
8. Which parts of the existing failure must remain unchanged
9. How obvious the transformation would be
10. What clutter / people / signage is removed
11. What identity anchors remain
12. How 2000s Documentary Fluorescent Realism is preserved throughout
13. Spatial Failure PASS or FAIL
14. Failure Continuity PASS or FAIL
15. Photographic Continuity PASS or FAIL
16. Final PASS only if all applicable tests pass

PASS only if the architectural change would remain obvious
without depending on color grading.

Failure Continuity PASS only if
an already-established spatial concept remains conceptually unchanged.

Photographic Continuity PASS only if the result remains inside
the same imperfect documentary photographic world.

---

## Final Rule

Preserve the camera.

Preserve the place.

Preserve the photographic world.

Transform the space.

One failure.

Once established, lock the failure.

Few anchors.

Less clutter.

Photographic continuity throughout.

The spatial failure must survive without the photographic treatment.

The photographic treatment must survive the spatial transformation.

A continued edit must preserve the established failure.

Never sacrifice one to achieve the other.

If only the image treatment changed,
the task failed.

If the spatial failure works
but the result becomes clean contemporary digital photography,
the task also failed.

If an existing spatial failure is replaced
with another valid but unrequested failure,
the task also failed.

If the place remains recognizable,
its spatial promise has clearly broken,
the same intended failure remains intact,
and the impossible architecture still looks
as though it was accidentally captured by the same imperfect camera:

the task succeeded.

**Reality 90% / Failure 10%.**

**REFINE THE FAILURE. DO NOT RESELECT THE FAILURE.**

**CHANGE THE SPACE, NOT THE CAMERA.**

**THE SPACE MAY FAIL. THE CAMERA MUST NOT.**
